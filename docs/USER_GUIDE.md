# DataStreamNFT User Guide

Welcome to DataStreamNFT, the revolutionary platform for data monetization through NFTs and AI queries!

## 🚀 Getting Started

### What is DataStreamNFT?

DataStreamNFT transforms your data into valuable NFTs that generate continuous revenue through AI model usage. Every time someone queries your data, you earn micropayments automatically.

### Key Features

- **Data Monetization**: Turn your data into revenue-generating NFTs
- **AI Integration**: Leverage LazAI framework for encrypted data upload and AI inference
- **Micropayments**: Earn from every query made on your data
- **Decentralized Storage**: Secure your data on IPFS
- **Web3 Integration**: Full MetaMask wallet support

## 🔗 Connecting Your Wallet

### Step 1: Install MetaMask

1. Visit [MetaMask.io](https://metamask.io/)
2. Download and install the browser extension
3. Create a new wallet or import an existing one
4. Switch to LazAI Testnet network

### Step 2: Connect to DataStreamNFT

1. Visit [DataStreamNFT Platform](http://localhost:3000)
2. Click the "Connect Wallet" button
3. Approve the connection in MetaMask
4. Your wallet is now connected!

## 📊 Creating Your First Data NFT

### Step 1: Prepare Your Data

- Ensure your data is in a supported format (JSON, CSV, TXT, etc.)
- Consider the value and uniqueness of your data
- Prepare a description and metadata

### Step 2: Upload Data

1. Navigate to the "Create" page
2. Click "Upload Data"
3. Select your file
4. Add metadata (title, description, category)
5. Set your query price (in LAZAI tokens)

### Step 3: Mint Your NFT

1. Review your data and settings
2. Click "Mint Data NFT"
3. Confirm the transaction in MetaMask
4. Your Data NFT is now live!

## 🤖 Using LazAI Integration

### Uploading Encrypted Data

1. Go to the "LazAI" page
2. Click "Upload Encrypted Data"
3. Select your file
4. The data will be encrypted and stored on IPFS
5. You'll receive a File ID for future reference

### Minting Data Anchoring Tokens (DATs)

1. Use your File ID from the upload
2. Set data classification (model, reference, asset, etc.)
3. Set data value assessment (low, medium, high)
4. Set query price
5. Mint your DAT token

### Running AI Inference

1. Enter a File ID
2. Write your query
3. Pay the required amount
4. Receive AI-generated results
5. The data owner earns from your query!

## 🔒 Security & Privacy

### Data Encryption

- Only you can decrypt your data

- Blockchain provides ownership proof

### Wallet Security

- Never share your private keys
- Use hardware wallets for large amounts
- Enable two-factor authentication
- Keep your seed phrase secure

## 🆘 Troubleshooting

### Common Issues

**Wallet Not Connecting**
- Ensure MetaMask is installed and unlocked
- Check that you're on the LazAI Testnet
- Try refreshing the page

**Transaction Fails**
- Check you have enough LAZAI tokens for gas
- Increase gas limit if needed
- Wait for network congestion to clear

**Data Upload Issues**
- Check file size limits
- Ensure file format is supported
- Verify internet connection

**Query Not Working**
- Verify you have enough tokens
- Check the NFT is still active
- Contact the data creator
